# 画像が「考える」日、企業エージェント元年、漏洩モデルの衝撃――生成AI最新動向
*2026年4月22日 | OpenAI・Google・Anthropic・Reddit r/singularity*

## OpenAI「ChatGPT Images 2.0」――画像生成に初めて思考が宿る

OpenAIは**4月21〜22日**にかけて画像生成モデルの大幅刷新版**gpt-image-2**を「ChatGPT Images 2.0」として投入した。同社の画像モデルとしては初めて**ネイティブの推論（thinking）**をアーキテクチャに組み込み、生成前に構図・レイアウト・テキスト配置を計画する「エージェント的画像生成」が現実のものとなった。

| 主要アップデート | 内容 |
|---|---|
| 推論モード | 生成前にWeb検索・レイアウト検討・検証を実行 |
| 解像度 | 2K対応、アスペクト比3:1〜1:3 |
| 一貫性 | 単一プロンプトから最大**8枚の連続画像**をキャラ・物体の同一性を保ったまま生成 |
| 多言語テキスト | **日本語・韓国語・中国語・ヒンディー語・ベンガル語**の高密度文字描画に対応 |
| 料金 | 入力$8.00／出力$30.00（画像） |
| 提供階層 | Thinkingモードは Plus/Pro/Business/Enterprise、Instantモードは無料枠含む全ユーザー |

DALL-E 2／3は**5月12日に廃止**され、gpt-image-2が全面的に後継となる。

> 「生成AIはついに『描く前に考える』フェーズに入った」——The New Stack

## Google Cloud Next 2026：エージェントプラットフォームとTPU第8世代

同日4月22日、ラスベガスで開催中の**Google Cloud Next 2026**でSundar Pichai CEOが複数の大型発表を行った。中核は、企業向けにエージェント開発〜運用〜統制を単一基盤に集約する「**Gemini Enterprise Agent Platform**」だ。

- **200以上のモデルへのファーストクラスアクセス**: Gemini 3.1 Pro/Flash、オープンソースのGemma 4、音楽生成のLyria 3、さらに**Anthropic製Claude Opus／Sonnet／Haiku**も利用可能
- **Agent Designer・Inbox・Skills・Projects**: エージェント運用に必要な発見・作成・共有・実行を一括管理
- **Agentic Data Cloud**: クロスクラウドLakehouseとKnowledge Catalogを統合
- **Agentic Defense**: GoogleのThreat IntelligenceとWizのクラウド/AIセキュリティ基盤を結合

ハードウェア面では**第8世代TPU**を公開。**TPU 8t（訓練向け）**は9,600基までスケールし2PBの共有メモリを備え、前世代Ironwood比3倍の処理能力を実現。**TPU 8i（推論向け）**は1,152基を単一Podで接続し、低遅延で数百万のエージェントを安価に同時運用できる。

> 「第一党モデルへのAPI経由のトークン処理量は毎分160億に達した。前四半期の100億から大幅増だ」——Sundar Pichai

Gemini Enterpriseの**有料月間アクティブユーザーは前四半期比40%増**と、企業市場の浸透は加速している。

## Anthropic「Claude Mythos」漏洩とProject Glasswingに亀裂

一方、生成AI業界を最も揺るがしたのは**4月21日に表面化したAnthropicのインシデント**だった。同社が「過去最強」と評し**公開を見送った**フロンティアモデル**Claude Mythos Preview**について、第三者ベンダー環境経由で不正アクセスがあったことが確認された。

**事件の経緯**：

| 日付 | 出来事 |
|---|---|
| 3月26日 | 社内CMSの設定ミスで約3,000件の未公開アセットが一時的に公衆インターネットへ露出。Mythosの発表下書きが発見される |
| 4月7日 | Anthropicが**Project Glasswing**を公式発表。AWS・Apple・Broadcom・Cisco・CrowdStrike・Google・JPMorganChase・Linux Foundation・Microsoft・NVIDIA・Palo Alto Networks等12社にのみ防衛的サイバー用途で限定提供 |
| 4月21日 | Discord上のグループが共有された契約者アカウントとAPIキーを悪用し、ベンダー環境経由でMythosにアクセス。Anthropicが調査中と声明 |

Claude Mythosは「既知のOS・主要ブラウザの**数千件のゼロデイ脆弱性を単独で発見**できる」として公開を断念された経緯があり、外部流出の懸念はセキュリティ業界全体に波紋を広げている。

> 「Mythosが示すのは、AIが熟練人間を除くすべてのコーダーを凌駕する脆弱性発見能力に達したという事実だ」——Anthropic内部文書（Foreign Policy誌報道）

## Reddit r/singularityのムード――「Spud」はどこへ？

Reddit最大のAI関連コミュニティ **r/singularity** では、今月のムードを象徴するコメントが拡散した。

> 「ベンチマークは上がっていくのに、モデルのバージョンを追いかける自分の能力は下がっていく」——r/singularity 投稿

噂の中心は、OpenAI次期モデル**GPT-5.5（コードネーム「Spud」）**だ。以下が現時点で判明している点と未確認の点である。

- **確認済み**: 3月24日に事前学習完了、現在は安全性評価フェーズ
- **Greg Brockman（OpenAI共同創業者）の発言**: 「2年間の研究の結晶で、大型モデルの感触がある。インクリメンタルな改善ではない」
- **未確認の期待機能**: SVG生成、フロントエンドデザイン自動化、エージェントワークフローの大幅強化、**3Dインタラクティブ世界の生成**
- **リリース時期**: 4月14日のリーク情報が外れ、21日時点でAltmanのツイートもブログもなし。r/singularityの共通見解は「数週間〜数ヶ月先、GPT-6はさらにその先」

同時期、Claude Opus 4.7とGPT-5.4の比較投稿にも活気があり、コミュニティの結論は**「どちらかを選ぶな、両方走らせろ」**。コーディング文脈ではClaude、調査・数理ではGPT、といった使い分けが定着しつつある。

## 示唆：2026年春の生成AI3つの地殻変動

| 変動 | 象徴する出来事 | 意味 |
|---|---|---|
| **画像の推論化** | ChatGPT Images 2.0 | 画像生成が「描画」から「計画+描画+検証」へ |
| **エージェント基盤戦争** | Gemini Enterprise Agent Platform・TPU 8世代 | 単発モデル競争から「マルチモデル統治+インフラ」へ |
| **能力と安全の乖離** | Claude Mythos漏洩 | 「公開しないほど危険」なモデルが既に流通経路を脅かす現実 |

**モデル単体のベンチマーク勝負**から**エージェント基盤・ガバナンス・セキュリティ**へと競争軸が一気に移動した4月22日。Redditのユーザーが感じる「追いかけきれなさ」は、単なる情報過多ではなく、**生成AIが産業構造そのものを書き換えるフェーズに入った**ことを示している。
