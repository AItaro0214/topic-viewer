# 言葉・ジェンダー・家族：現代社会を映す心理学研究
*2026年4月1日 | PsyPost*

## 「言葉は傷つける」という信念とうつ・政治イデオロギーの関係

「言葉は長期的な心理的ダメージを与える」という信念は、どのような人に強く、どのような結果をもたらすのか。956名の米国成人を対象に実施された縦断研究（2週間後に再調査）が、その実態を明らかにした。研究チームは「言葉は有害である尺度（WCHS）」という10項目の測定ツールを新たに開発し、この信念と政治的立場・メンタルヘルスとの関連を分析した。

| 変数 | 関連の方向と強さ |
|------|----------------|
| 進歩的・民主党寄りの政治的志向 | 強い正の相関 |
| 制度的な検閲への支持 | r = 0.52（非常に強い） |
| うつ・不安症状 | 有意な正の関連 |
| 感情的回復力（レジリエンス） | 有意な負の関連 |
| 被害者意識の高さ | 有意な正の関連 |

若い世代・女性・非白人においてスコアが高い傾向も確認された。

> 「これらの結果は、言論の自由、セーフスペース、政治的正しさをめぐる現代の文化的分断を理解する上で重要な手がかりを与える。」――研究著者のサム・プラット

- **因果関係の留意点**: 研究は相関研究であり、信念がうつを引き起こすのか、うつが信念を形成するのかは未解明
- **理論的意義**: 心理的傷つきやすさの感覚がイデオロギーと結びつくメカニズムの解明に向けた第一歩
- **社会的示唆**: 「言葉の危険性」をめぐる議論を、個人の心理状態と切り離して論じることの難しさを浮き彫りにする

## トラッドワイフを支持する男性の本音：軽蔑が潜む伝統志向

「トラッドワイフ（伝統的な専業主婦）」スタイルを称賛する男性たちは、実際のところ、その女性たちをどう見ているのか。18〜29歳の米国男性595名を対象にした研究が、その複雑な実態を解き明かした。研究では、トラッドワイフムーブメントへの親しみと賛否を測定するとともに、**敵対的性差別**（女性への露骨な敵意）と**温情的性差別**（保護主義的な騎士道的態度）の2種類の偏見尺度も測定した。

- **予想外の結果**: 研究者が想定していた「保護主義的態度」ではなく、「敵対的性差別」がトラッドワイフ支持の最大の予測因子だった
- **自由記述の傾向**: 一部の参加者はトラッドワイフ女性を「怠けて本物の仕事を避ける人々」と描写
- **パラドックス構造**: 伝統的な性別役割を望みながら、その役割を担う女性を同時に軽蔑している

> 「トラッドワイフの女性たちは不安定な立場に置かれている。自分を軽蔑するかもしれない夫に、財政的に依存しているからだ。」――著者のラシェル・ロブネット

この研究は、表面上「伝統的な家族観」に見える支持の背後に、ミソジニー（女性嫌悪）が潜んでいる可能性を示す。保守的な言説が女性の尊厳とどのように交差・衝突するかを問い直す上で、重要な実証的知見だ。

## 親子の会話が育む10代のソフトスキルと感情の安定

感情コントロールや社会的スキルなどの「非認知能力」は、学業成績・就職・精神的健康に深く関わることが知られている。では、これらの能力を育むうえで家庭環境はどのような役割を果たすのか。中国教育パネル調査のデータ（中学2年生5,055名）を分析した研究は、**親子間コミュニケーションの質**が非認知能力に直接・間接的に影響することを明らかにした。

- **直接効果**: 親子の対話が多いほど、自制心・感情調整・社会的スキルが高い
- **間接効果の連鎖**: 良い親子コミュニケーション → 社会的サポートの充実 → 身体活動の増加 → 非認知能力の向上
- **顕著なグループ**: 都市部の子ども・一人っ子でこの効果がより強く現れた

| 経路 | 効果の性質 |
|------|------------|
| 親子対話 → 非認知能力（直接） | 統計的に有意 |
| 親子対話 → 社会的サポート → 身体活動 → 非認知能力 | 間接的な媒介効果 |
| 都市部・一人っ子 | 効果がより顕著 |

> 「日常的な親子の対話は、子どもの長期的な人生成果を予測する能力の形成において、核となる役割を果たす。」

スマートフォンやデジタルメディアによって親子の対面コミュニケーションが減少していると言われる現代において、この研究は実践的なメッセージを持つ。学校での指導だけでなく、家庭での会話の「量と質」への意識的な投資が、子どもたちの社会的・感情的発達にとって不可欠であることを改めて示している。
